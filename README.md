# Moving Help

A front-end marketplace for moving-service providers and customers.

## Local development

```bash
npm install
npm run dev
```

## GitHub Pages

The project is configured for `https://ironmanr24.github.io/moving-help/`.
Every push to `main` deploys the latest production build through GitHub Actions.

For a manual deployment from a machine with GitHub access, run:

```bash
npm run deploy
```

The provider portal uses hash routing on Pages: `#/provider`.
